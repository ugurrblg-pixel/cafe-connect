# Activity surface

## Direction contract

THESIS: public plans provide a reason to meet; the map shows plans, not a crowd of tracked people.

OWN-WORLD: inherit Riyo's existing coral, white/cool-gray surfaces, Inter, rounded cards and outline icons. Use the shared semantic tokens and Button/Input/AlertDialog owners. The owner-approved concept is the visual authority; no new brand system is introduced.

STORY: explore map and categorized list → open a plan → request admission → host accepts → group conversation. Creation uses details → public-location preview/consent → publication.

SIGNATURE: compact event pins with actual capacity counts, a selected event card and a restrained coral create action. Zero fake participants or activity counts.

INTERACTION: the list is a complete keyboard-accessible alternative to map pins. Form fields use native date/time and number inputs intentionally; map panning plus “Harita merkezini seç” provides a keyboard selection path. All pending, full, rejected, unavailable, empty and failed states remain distinct.

RESTRAINT: no individual location dots, fabricated portraits, implied venue endorsement, automatically public photos, unsupported push claims or Google-derived map coordinates.
